# AI 時代的共生橋｜互補合作示範原型

課程期末專案的示範原型：讓服務團隊刊登能力與需求、找到互補夥伴、送出合作邀請並查看進度。

**線上 Demo：<https://ldsas.github.io/symbiosis-bridge-demo/>**

## 兩分鐘示範

1. 選「刊登能力／需求」，輸入名稱、能力與需要的幫助，送出刊登。
2. 在「探索互補能力」依「話務」或關鍵字篩選夥伴。
3. 按「提出合作邀請」，填寫合作目的並送出。
4. 在「合作進度」更新為「洽談中」，重新整理後資料仍保留。
5. 用頁尾的「重設示範資料」恢復初始情境。

頁面上方的四步流程會標示已完成的步驟。

## 範圍與限制

- 所有業者均為虛構示範資料，不代表真實公司或商業承諾。
- 資料只儲存在你自己的瀏覽器，不會上傳，也不會通知任何人。
- 已實作：刊登、關鍵字／類別篩選、合作邀請、重複邀請阻擋、狀態更新、本機保存及重設。
- 沒有後端帳號、真實通知、金流、正式 API 或 AI 模型。
- 狀態「已達成合作意向」只代表雙方同意合作，不等於完成交付。
- 請勿輸入客戶個資或真實機密。

## 離線使用

下載 `index.html`，用 Chrome 或 Edge 直接開啟即可，不需安裝任何套件。
